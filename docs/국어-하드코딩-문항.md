# 하드코딩 국어 문항

파이프라인이 영상에서 국어 문항을 뽑기 전까지 쓰는 손으로 쓴 문항이다.
2019 개정 누리과정 **의사소통** 영역에 맞춰 두 나이대로 나눠 두었다.

- 파일: `frontend/data/korean-pool.js`
- 고르는 기준: 아이 생년월일로 계산한 개월 수. **72개월(만 6세)** 이상이면 7세용, 아니면 4세용.
  나이를 모르면 4세용을 준다 — 너무 쉬운 문항은 잠깐 심심할 뿐이지만, 너무 어려운 문항은
  아이가 다음에도 안 하려 들게 만든다.
- 보기는 화면에서 매번 섞인다. 아래 표의 순서는 파일에 적힌 순서일 뿐이다.
