## 1. ASR 환각 — 23.5% → 0.0%

**측정 방법.** 반복 루프·타임스탬프 붕괴·불가능한 발화속도를 탐지하는 결정적 판별기로
전체 전사 구간 중 환각 구간의 **초 단위 합**을 재고 전체 대비 비율을 낸다.

```python
(top_token_count >= 5 and top_ratio > 0.6)   # 반복 루프
or duration <= 0.01                           # 타임스탬프 붕괴
or len(text) / duration > 12                  # 물리적으로 불가능
```

| 설정 | 세그먼트 | 적발 | 환각 구간 | 비율 |
| --- | ---: | ---: | ---: | ---: |
| `large-v3-turbo` 기본 | 160 | 13 | 163초 / 694초 | **23.5%** |
| `large-v3-turbo -mc 0` | 165 | 9 | 122초 | 18.9% |
| `-mc 0` + 도메인 프롬프트 | 165 | 9 | 122초 | 18.9% |
| **`small -mc 0`** | 197 | 3 | 50초 | **9.1%** |
| **`turbo` + Silero VAD** | 70 | 0 | 0초 | **0.0%** |

**부수 발견 셋.**

- **3배 작은 모델이 2.6배 정확했다.** `small`(465MB) 9.1% vs `large-v3-turbo`(1.5GB) 23.5%.
- **도메인 프롬프트는 효과가 0이었다.** 등장인물 이름을 프롬프트에 넣어도 수치가
  소수점까지 동일했고 `크랑 → 크롱` 교정도 되지 않았다. 사전이 따로 필요한 이유다.
- **VAD는 환각을 0으로 만드는 대신 재현율을 잃는다.** 세그먼트 160 → 70.
  101초 구간이 네 단어로 압축되고 엔딩 주제가가 통째로 소실됐다.

```bash
whisper-cli -m models/ggml-large-v3-turbo.bin -f work/뽀로로1화.wav -l ko -oj -of /tmp/a
whisper-cli -m models/ggml-large-v3-turbo.bin -f work/뽀로로1화.wav -l ko \
            --vad --vad-model models/ggml-silero-v5.1.2.bin -oj -of /tmp/b
```

## 3. 거짓 `high` 등급 — 70 → 10 (7배 정화)

**"사전이 손대면 high"** 로 짰더니 이름 교정만으로 최고 신뢰도가 붙었다.

```
[high] 크롱! 크롱!              ← 옹알이가 최고 등급
[high] 엿돌디볼! 크롱! 크롱!     ← 같은 세그먼트에 이름이 있다는 이유로 쓰레기가 high
```

뽀로로 214 세그먼트에서 `high` 70건 중 **약 60건이 이름 반복**이었다.
내용성 필터(이름·감탄사를 걷어내고 내용 토큰 2종 이상)를 넣은 뒤 70 → **10**.

`high` 가 줄어든 것이 개선이다. 이름 교정은 **그 이름만** 검증하지 문장 전체를 보증하지 않는다.

## 8. 활동 생성 — 6채택/5폐기 → 12채택/0폐기 (타요)

| | 채택 | 폐기 | 개수 세기 | 색깔 퀴즈 |

| 수정 전 | 6 | 5 | **0** (전멸) | **0** (전멸) |

근거 채널이 다르면 검사도 달라야 한다. 시각 근거형은 `프레임 실재 + 검증자 직접 확인`,

**실제 생성 결과 (5편 중 2편 완료).**

| 작품 | 개입지점 | 채택 | 유형 분포 |

| 뽀로로 | 2 | **7** | 연관성 2 · 그림 2 · 문장배열 1 · 의성어 1 · 개수 1 |

## 9. 게이트가 실제로 차단한 것 — 2종

**연출이 아니라 실제로 발생한 사례다.**

```
[폐기] 개수 세기   인용 위조
       quote "친구들이 모여 있어요"  ∉  원문 "뽀로로와 크롱은 정말 꿈을 꾼 걸까요?"
       → 생성자가 시각 증거 없이 개수 문제를 만들려다 없는 대사를 지어냈다

[폐기] 의성어      정답 조작
       quote "꿰매기 시작했어요"  ← 원문에 실재. 인용 게이트는 통과한다
       answer "쓱쓱"             ← 증거 어디에도 없음. 정답 게이트가 잡았다
```

두 번째가 설계상 중요하다. **인용만 검사하는 게이트는 이것을 통과시킨다.**

`grounding.py` 자체검사 **17/17 통과**. 뽀로로 초기 7카드 판정:
`grounded 3 · open_ended 2 · ungrounded 2`.

## 12. 이름 자동 수렴 — 두 번의 오류

**오류 A — 빈도로 대표형을 고르면 오답이 정답을 덮어쓴다.**

```
자동 선택 결과:  크랑 ← {클랑, 크롱}
```
ASR이 크롱을 크랑으로 자주 잘못 듣기 때문에 **오답이 최빈형**이 된다.
자동 확정을 폐기하고 군집만 제안, 대표형은 사람이 확정. **미확정이면 치환하지 않는다.**

**오류 B — 정상 곡용형을 오인식으로 잡아먹는다.**

```
자동 선택 결과:  뽀로뽀로 ← {뽀로로, 뽀로로와}
```
`뽀로로와` 는 조사가 붙은 정상형인데 변이형으로 묶여 `뽀로뽀로` 라는 쓰레기가 될 뻔했다.
조사 제거(`stem()`) 후 군집이 정상화:

```
크롱   ← 크랑
뽀로로 ← 뽀로롱, 보르로
```

**자모 유사도 실측** — `크롱`/`크랑` 0.83, `크롱`/`이불` 0.17, `뽀로로`/`보로로` 0.89.

## 13. 장면 경계 신호 — 작품마다 지배 신호가 뒤집힌다

내레이터가 없는 작품의 경계를 무음 공백 하나로 잡으면 라벨에 의미가 없다.

```
전:  (무음 전환 바범이 훌륭다!)
후:  티니핑들·깡총
```

**신호별 실제 기여도 (채택된 경계에서 측정).**
