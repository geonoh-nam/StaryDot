**검증일 기준 산출물** — 4개 작품 · 개입지점 7곳 · 활동 26건 채택 / 2건 폐기 (게이트 통과율 93%)

## 3. 게이트가 실제로 걸러낸 것

연출이 아니라 실행 중 발생한 사례다.

### 3-1. 인용 위조 — 없는 대사를 지어냄

```
[폐기] 개수 세기
   quote  "친구들이 모여 있어요"
   원문   "뽀로로와 크롱은 정말 꿈을 꾼 걸까요?"   ← 일치하지 않음
```
생성자가 시각 증거 없이 개수 문제를 만들려다 대사를 창작했다.

### 3-2. 정답 조작 — 인용은 진짜, 정답만 지어냄

```
[폐기] 의성어·의태어
   quote   "꿰매기 시작했어요"   ← 원문에 실재. 인용 게이트는 통과한다
   answer  "쓱쓱"                ← 증거 어디에도 없음
```
**인용만 검사하는 게이트는 이것을 통과시킨다.** 정답 근거 검사를 따로 만든 이유다.

### 3-3. 검증자가 프레임을 열어 반박

```
[폐기] 색깔 퀴즈  "눈 내린 마을 위 하늘은 무슨 색? → 파랑"
   검증자: "f0004 를 직접 열어 보니 화면 상단은 눈 덮인 설산이 대부분을 차지하고
            하늘은 거의 드러나지 않으며, 보이는 좁은 띠도 흰색~연회색으로 흐리다.
            정답 '파랑'에 해당하는 파란 하늘이 화면에 없다."
```
생성자가 색 팔레트만 보고 "파랑이 허용 색이니 하늘은 파랑"이라 추론했는데,
검증자가 **실제 픽셀을 확인해 반박**했다. 독립 검증이 형식이 아님을 보여준다.

### 3-4. 연령 수준 초과 — 정답은 맞는데 문제가 어렵다

```
[폐기] 색깔 퀴즈 (3세)  "맨 오른쪽 끝 버스는 무슨 색?"
   검증자: "맨 오른쪽 끝 버스가 파랑인 건 맞고 파랑은 허용 색이나,
            '맨 오른쪽 끝'은 좌우 변별을 요구한다. 좌우 방향 개념은 5세 수준이다."
```
**정답은 옳다.** 그런데 질문이 요구하는 인지 수준이 대상 연령을 넘는다.
누리과정 발달 수준표를 검증자에게 준 결과다. 정답 검사만으로는 못 잡는 유형이다.

### 3-5. 근거 없는 낱말

```
[폐기] 이야기 이해  정답 "열어봐요" — 내용 형태소 0/1, 증거에 없음
```

| 영역 | 건수 | 대표 활동 |

| 의사소통 | 7 | 이야기 이해, 낱말 알기, 문장 배열 |
| 사회관계 | 7 | 마음 읽기, 도움 주고받기, 내가 그 자리라면 |
| 자연탐구 | 6 | 개수 세기, 크기 비교, 원인과 결과 |
| 예술경험 | 6 | 색깔 퀴즈, 장면 감상, 그림으로 표현 |

**한 지점에 여러 영역이 고르게 배치됐다.** 뽀로로 7:35 와 11:00, 타요 4:35 는
각각 4개 영역이 1건씩 들어갔다. 연관성 문제만 네 개 나오는 것을 막기 위해
스킬에 "서로 다른 영역을 섞어라"를 명시한 결과다.

**연령 분포** — 3세 11 · 4세 7 · 5세 8. 세 연령이 고르다.

**창작형 비율** — 26건 중 7건(27%)이 정답 없는 활동(장면 감상, 그림으로 표현,
내가 그 자리라면, 이어질 말 상상). 누리과정이 정답 맞히기보다 **표현과 참여**를
앞에 두기 때문에 의도적으로 확보했다.

## 5. 경계선에 걸린 것 — 통과시켰지만 기록해 둔다

### 5-1. 타요 1:54 색깔 퀴즈 — 오답 보기가 화면에 있다

```
Q. 길 가운데 멈춰 있는 큰 트럭은 무슨 색일까요?
   노랑 / 분홍 / 초록   → 노랑
```
정답은 유일하다(가운데 큰 트럭은 확실히 노란 덤프트럭). 그런데 **화면 위쪽에
초록 트럭이 실제로 있다.** 질문이 "가운데 큰"으로 한정해서 성립하지만,
유아가 화면 전체를 훑으면 혼동할 수 있다. 오답 안전성 기준으로는 경계선이다.

> 개선안: 오답 보기를 `absent` 팔레트(면적 0.5% 미만)에서만 뽑도록 스킬에 못 박기.

### 5-2. 뽀로로 7:35 장면 감상 — 서술이 살짝 어긋난다

```
Q. 친구들이 하얀 이불을 함께 고치고 있어요. 어떤 느낌이 드는지 말해 보아요.
```
그 순간 화면에서 실제로 하는 일은 **곰인형에게 줄 솜이불을 만드는 것**이다.
직전 내레이션("곰인형은 찢어진 이불을 꿰매기 시작했어요")과 화면 사이에 시차가 있다.
창작형이라 틀린 답을 가르치지는 않지만, 서술이 정확하지는 않다.

## 7. 남은 한계 — 정직하게

- **티니핑 본편 끝이 `[tail]` 폴백이다.** 5편 중 유일하게 노래 구간도 내레이션도
  못 찾아 "전사본 마지막"으로 잡았다. 12:41 개입이 엔딩 크레딧 안일 가능성을 배제하지 못한다.
- **티니핑·아기상어는 개입지점이 1곳뿐이다.** 근거 5건 기준을 못 넘어 나머지가 기각됐다.
  기준을 낮추면 활동은 늘지만 근거가 얇아진다. 지금은 얇은 쪽을 버리는 선택을 유지한다.
- **브레드는 0곳이다.** 대사가 쉬지 않아 페이드아웃 3초를 확보할 수 없다.
- **교육 효과는 미검증.** 이 문서가 확인한 것은 *"활동이 증거에 근거하고 연령에 맞는가"*
  까지다. *"그래서 아이가 실제로 배우는가"* 는 사용자 연구가 필요하다.
- **검증자도 LLM이다.** 결정적 게이트가 최후 방어선인 이유이며, 게이트가 못 잡는
  유형(연령 초과, 오답 모호성)은 검증자에 의존한다. 이 의존은 남아 있다.
