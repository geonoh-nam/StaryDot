# 파이프라인 전편 실행 · 시딩 · 25분 시나리오 검증

2026-08-27 새벽 작업 기록. 아침에 이 파일부터 보면 된다.

## 한 줄 요약

영상 29편을 파이프라인에 돌려 **문항 300개**를 DB에 실었고 25분 예산으로 편성하면
`[영상] → [활동 2문항] → [영상] → [활동 2문항] → [마무리 미션]` 이 실제로 나온다.
아이 나이에 따라 문항이 갈리는 것까지 확인했다.

## 1. 파이프라인

29편 전부 완주했다. 실패한 편은 없다.

```
storydot.py   영상 → 세그먼트·개입지점        work/<id>_plan.json
facts.py      → 재료 인덱스 (LLM 없음)        work/<id>_facts.json
observe.py    → VLM 관찰 + 팔레트 반증        work/<id>_screen.json
generate3.py  → 문항 (연령 칸마다 1회 호출)    work/<id>_final.json
```

중간에 두 가지를 고쳐야 굴러갔다.

- `pipeline/facts.py` — 영상을 `~/Downloads` 에서만 찾았다. 이 저장소의 영상은
  `backend/server/media/video/` 에 있으므로 그 경로를 먼저 보도록 `VIDEO_DIRS` 에 더했다.
- `claude` CLI 로그인이 만료돼 관찰 단계가 통째로 실패했다. 다시 로그인한 뒤,
  `observe.py` 는 실패한 관찰도 캐시에 남기므로 `--refresh` 로 다시 돌려야 했다.

### 고친 버그 하나

`backend/server/activity-payload.js` 의 색 이름 표에 **"흰색"이 없었다.** 파이프라인

## 3. 25분 시나리오

`GET /plan?character_id=teenieping&budget_sec=1500` 결과다.

```
[영상]   캐치 티니핑 3화 (699초)
[활동]   이 그림에서 헬멧은 무슨 색인가요? / 이 그림에서 화분은 무슨 색인가요?
[영상]   캐치 티니핑 4화 (699초)
[활동]   이 그림에 노란 상자 1개와 검은 안경 1개… / 이 그림에 초록색 나무 5개와…
[마무리] 나만의 옷 고르기
총 1498초 / 예산 1500초
```

원했던 `영상 → 국어 → 수학 → 영상 → 그림` 과 형태는 같다. 다만 **지금 브레이크에 실리는
문항은 전부 파이프라인 산물**이라 국어/수학이 칸마다 갈리지는 않는다. 그렇게 하려면
편성기가 브레이크마다 영역을 지정해 뽑도록 고쳐야 한다(아래 남은 일).

### 나이에 따라 갈리는지

같은 티니핑, 같은 25분인데 아이만 바꿨다.

- **네 살** — 헬멧 색(4세) · 화분 색(4세) → 하얀 양말 개수(3세) · 동그라미 찾기(3세)
- **일곱 살** — 하얀 창문 3개와 인형 1개…(7세) · 새 2마리와 나무 1그루…(6세) → 모자와 창문(6세)

`getCatalog(childAge)` 가 아이가 감당 못 하는 나이의 문항을 빼고, 남은 것을 나이 내림차순으로
정렬해서 준다. 검증용으로 `demo-4`, `demo-7` 두 아이를 DB에 넣어 뒀다.

### 뽀로로가 한 편만 나오는 것은 정상

뽀로로는 한 편이 762초(12.7분)라 두 편이면 25.4분이다. 25분 예산에 안 들어간다.
편성기는 예산을 넘기지 않으므로 한 편 + 브레이크 + 미션(822초)에서 멈춘다.
30분으로 잡으면 두 편이 들어간다.

## 4. 남은 일

1. **브레이크마다 영역 지정** — "첫 브레이크는 의사소통, 둘째는 자연탐구" 같은 규칙이 편성기에
   없다. 지금은 그 영상에 달린 문항에서 순서대로 집는다.
2. **하드코딩 국어 24개가 DB 밖에 있다** — `frontend/data/korean-pool.js` 에 있어서 편성기가
   모른다. 국어 칸을 확실히 채우려면 이것도 `activity` 행으로 넣어야 한다.
   (문항 목록은 `docs/국어-하드코딩-문항.md`)
3. **의사소통 문항이 41개로 가장 적다** — 파이프라인이 뽑는 국어 유형이 지금은 "누가 나왔나"
   정도뿐이다. `pipeline/skills/quiz3/SKILL.md` 에 국어 유형 8종을 더할 여지가 있다
   (사물 이름 대기 · 꾸미는 말 붙이기 · 첫소리 찾기 · 흉내내는 말 · 문장 완성 등).
4. **패드 확인** — 새벽 작업은 전부 서버 쪽이다. 앱에서 실제로 브레이크가 뜨는지는 패드를
   연결해서 봐야 한다. (어젯밤 USB가 빠져 있었다)

## 실행 방법 메모

서버는 편성기가 TypeScript 라 플래그가 필요하다.

```bash
node --experimental-strip-types backend/server/index.js
```

파이프라인 한 편 더 돌리기:

```bash
cd pipeline
python3 storydot.py ../backend/server/media/video/<id>.mp4
python3 facts.py <id> --write
python3 observe.py <id> --refresh
python3 generate3.py <id>
```

시딩은 이번에 인라인 스크립트로 했다. 반복해서 쓸 거면 `tools/seed-activities.js` 로 떼어
두는 게 좋다 — 지금은 이 문서의 절차가 유일한 기록이다.
